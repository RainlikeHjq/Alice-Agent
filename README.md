## 🌟 项目简介

**Alice Agent** 是一个具有"活人感"的AI个人助理。不同于传统AI助手的"一问一答、过目即忘"，Alice拥有**时间流逝感**——她知道昨天发生了什么，记得上周的重要事项，能感知时间的流动。

你不需要写一行代码，只需要用**纯自然语言**编写文档，就能构建一个与你同步成长的AI伙伴。

## 🧠 核心设计

### 1️⃣ 五级记忆系统

模拟人类记忆机制，实现**时间越近记得越清、时间越远记得越模糊**的自然效果。

```
每日记忆 → 周记忆 → 月记忆 → 季记忆 → 年记忆
```

- **加载策略**：只加载本周每天 + 上周 + 上月 + 上季度 + 去年（共约10份文档）
- **Token消耗**：满打满算约 **20k token**，不到上下文容量的2%
- **精确回溯**：通过高层记忆的时间戳和索引，可精准追溯任意一天的具体内容

### 2️⃣ 睡眠时刻 ⏰

借鉴人类睡眠机制，赋予AI"一天结束"的仪式感。

- **时间**：每晚 **23:30 - 23:50**
- **功能1**：自动将当天会话历史提炼为**每日记忆文档**
- **功能2**：逢周日/月末/季末/年末，自动触发**高级记忆提炼**
- **功能3**：自动关闭旧会话、创建新会话，保持记忆系统整洁

## 📦 快速开始

### 前置条件

- [Pi Coding Agent](https://example.com)（或其他支持跳出沙盒的harness）
- 一个愿意每天花30秒跟AI聊聊的你

### 安装(for pi)

```bash
git clone https://github.com/yourname/Alice-Agent.git
cd Alice-Agent
pi
```

输入以下提示词：

```
请创建以下周期循环任务：
- 每晚23:30使用longterm-mem-skill进行每日记忆生成。
- 每周日23:30使用longterm-mem-skill进行每周记忆生成。
- 每月最后一天23:30使用longterm-mem-skill进行每月记忆生成。
- 每季度最后一天23:30使用longterm-mem-skill进行每季记忆生成。
- 每年12月31日23:30使用longterm-mem-skill进行每年记忆生成。
- 以上任务若有重叠，从低级向高级依次执行。
- 每晚23:35检查记忆是否创建完成。若已完成，则使用wechat-new插件开启一个新的会话。
```

### 配置

1. 编辑 `AGENTS.md`中可编辑区域，完善Alice的身份、性格和工作职责等。
2. 在 `info/` 目录下填写你的基本信息、偏好等固定信息，以及其他你需要agent清楚的信息。

### 启动

```bash
pi
```

然后，像对待一个真实助理一样跟她说话吧。

## 💡 使用场景

- **日常记录**：每天做了什么，随时告诉她
- **待办管理**：让她帮你记住要完成的事
- **工作复盘**：回顾过去一周/一月的工作状态
- **生活助手**：规划行程、提醒事项、操作电脑
- **个人成长**：分析你的时间分配，帮你更了解自己

> "坚持一段时间之后，你会觉得一切都变得无比清晰。她会比你自己还懂你。"

---

## ⚠️ 注意事项

### 不适合的场景
- 需要长期精准记忆的**固定信息**（如项目信息、个人偏好）→ 请放入 `info/` 目录
- **跨天持续进行的长时间任务** → 建议在当前会话完成后再切换

### 推荐用法
- 做完每件事后花 **30秒** 告知Alice
- 有什么想法、灵感、待办，随时告诉她
- 坚持使用，效果随时间递增
